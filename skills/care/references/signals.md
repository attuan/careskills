# signals — フックによる観察

`scripts/observe.py` は `UserPromptSubmit` フックとして、本人が Claude Code に打つすべてのプロンプトを一瞬だけ見る。目的は、本人が作業に没頭して自分のしんどさに気づいていないときに、横から一言かけること。監視ではない。

## 仕組み

1. プロンプトを語彙と照合する。
   - **crisis**（死にたい、消えたい、自殺、kill myself …）: 即座に通知。クールダウンも一時停止も無視する。
   - **high**（限界、もう無理、眠れない、泣きそう、パニック …）: 2 点
   - **medium**（疲れた、しんどい、不安、焦る、締切、徹夜、怒られ …）: 1 点
   - 深夜（既定 1〜5 時）に打たれたプロンプト: +1 点
2. 直近 3 時間の合計（rolling）も見る。「疲れた」程度の語が 3 時間に 5 回出れば、一回の強い語と同じ扱い。
3. 通知するのは、そのプロンプト単体で 3 点以上、または rolling 5 点以上、かつ前回の通知から 90 分以上経っているとき。
4. 通知は `additionalContext` として Claude に渡る。内容は「普段どおり答えたうえで、末尾に 1〜2 文だけ気遣いを添えて」。本文は SKILL.md「フックからの通知を受けたとき」。
5. 台帳には `signal` 型で、一致した語・点数・レベル・通知したか、だけを残す。プロンプト本文は残さない。
6. `/care` で始まるプロンプトは見ない（スキルが対応中）。

## 調整

`$CARE_HOME/config.json` の `observe`:

```json
"observe": {"cooldown_min": 90, "threshold": 3, "rolling_threshold": 5, "rolling_hours": 3, "late_night": [1, 5]}
```

- 声かけが多すぎる → `threshold` を 4 に、`cooldown_min` を 180 に。
- 全く来ない → `threshold` を 2 に。
- 語彙を足す・減らす → `observe.py` の `CRISIS` / `HIGH` / `MEDIUM`。「無理」単体のように技術的な文脈で頻出する語は入れない（誤検知で煩わしくなると、スキルごと切られる）。
- 試す: `python3 -I scripts/observe.py --dry "もう無理、徹夜で間に合わない"`

## 止める

- `/care off`（無期限）／`/care off 6`（6 時間）／`/care on`
- フックごと外す: `scripts/uninstall.sh`（データは残る）

## 限界

- 語彙照合なので、皮肉や「疲れたと言っている人のログを解析して」のような文は誤検知する。だから通知は「一言添えて」に留め、Claude 側が文脈で判断する。
- 本人が丁寧語で淡々と書く人なら、語彙に引っかからない。その場合は `check` の習慣のほうが効く。
